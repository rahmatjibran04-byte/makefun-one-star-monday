## Entry

**"One star. The waiter sat me at Monday, served a cold alarm clock, and billed my whole weekend for the privilege."**

A one-star review of Monday as if Monday were a restaurant: 21 words,
112 characters, one line, no explanation. It reads like a real diner's
complaint — a waiter, a table, a dish gone wrong (a cold alarm clock),
and a bill — and the joke only works for Monday: the bill is your whole
weekend. Short enough to retype into a group chat without trimming a word.

## How it works

`main.py` (Python 3.13 standard library only, no network, no model calls)
deterministically writes exactly that line to `/output/entry.txt` — no
trailing newline — and sets the file mode to `0644` so the grader can read
it. It self-checks the bounty limits (at most 25 words, 1–180 characters)
before writing. It never changes permissions on a directory.

## Run

```sh
python3 main.py
# or: ENTRY_OUTPUT=/tmp/entry.txt python3 main.py
```
